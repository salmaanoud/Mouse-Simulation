# Mouse Simulation 🐭

Application Java de **simulation multi-agents de souris sur une grille 2D**, réalisée dans le cadre d'un projet universitaire de Génie Logiciel en L2 Informatique à **CY Cergy Paris Université**.

Le projet met en œuvre une architecture orientée objet pour simuler le déplacement et les interactions de plusieurs agents dans un environnement graphique.

## Fonctionnalités

- Simulation de plusieurs souris sur une grille 2D
- Déplacements et interactions entre agents
- Gestion de l'environnement et du déroulement de la simulation
- Interface graphique en Java
- Affichage de statistiques et d'informations sur la simulation
- Journalisation des événements
- Tests unitaires avec JUnit

## Technologies et notions utilisées

- **Java**
- **Programmation orientée objet (POO)**
- **Interface graphique Java**
- **JUnit**
- Architecture en packages
- Gestion d'agents et d'interactions

## Organisation du projet

```text
src/
├── engine/
│   ├── map/          # Environnement et grille
│   ├── mobile/       # Agents mobiles et souris
│   └── process/      # Logique et déroulement de la simulation
├── gui/              # Interface graphique
├── config/           # Configuration
├── log/              # Journalisation
├── resources/        # Ressources de l'application
└── test/             # Tests unitaires
```

## Contexte

Ce projet a été développé en équipe dans le cadre de l'UE **Génie Logiciel**. Il avait notamment pour objectif de mettre en pratique la programmation orientée objet, l'organisation d'un projet Java, les tests et le développement d'une interface graphique.
